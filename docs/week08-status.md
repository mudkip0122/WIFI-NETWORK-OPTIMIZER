## 프로젝트 평가 기준 week08-v1

아래 수치는 프로젝트 초기 기준이며 공인 표준이 아니다. 실환경 측정으로 보정한다.
각 절점 사이를 선형 보간하고 양 끝에서는 점수를 제한한다.

| 지표 | 입력값 → 점수 절점 | 가중치 |
|---|---|---|
| RSSI (dBm) | -100→0, -85→20, -75→40, -67→60, -55→90, -50→100 | 30 |
| 게이트웨이 Ping (ms) | 0→100, 5→100, 20→75, 50→40, 100→0 | 15 |
| 외부 Ping (ms) | 0→100, 20→100, 50→75, 100→40, 300→0 | 10 |
| 게이트웨이 손실 (%) | 0→100, 1→90, 3→75, 5→60, 10→40, 25→0, 100→0 | 20 |
| 외부 손실 (%) | 위와 동일 | 15 |
| 다운로드 | 목표 100 Mbps 대비 달성률, 최대 100점 | 7 |
| 업로드 | 목표 20 Mbps 대비 달성률, 최대 100점 | 3 |

속도 목표는 `evaluate_quality` 함수의 `download_target`, `upload_target`으로 변경할 수 있다.
GUI는 기본 목표를 사용한다. 채널과 대역만으로 혼잡을 판단하거나 감점하지 않는다.

종합 점수 = Σ(지표 점수 × 가중치) / 사용된 가중치 합.
등급은 반올림 전 점수 기준 90 이상 매우 좋음, 75 이상 좋음, 60 이상 보통,
40 이상 나쁨, 40 미만 매우 나쁨이다.

## 누락·실패 처리 및 비교 한계

- 미측정·실패 속도는 제외하며 이전 값을 재사용하지 않는다. 유효한 0 Mbps는 0점이다.
- RSSI와 최소 한 개의 Ping 또는 손실 지표가 있어야 종합 평가한다.
- Ping 송신 표본이 없으면 지연·손실을 제외한다. 무응답 100% 손실은 0점이며 지연은 제외한다.
- 실패·취소·측정 경고가 있는 결과는 종합 평가하지 않는다.
- NaN, 무한대, 잘못된 범위·타입은 제외한다.
- 평가 범위는 사용된 원래 가중치의 합이다. 서로 다른 사용 지표·목표의 점수를 직접 비교하지 않는다.
- 짧은 Ping 표본은 손실률 변동성이 크다. JSON에 표본 수와 안내를 제공한다.
- 외부 Ping·속도는 인터넷 경로·서버 영향을 포함하며 Wi-Fi 원인으로 단정하지 않는다.
- RSSI 실측·추정 출처는 기존 Dashboard와 JSON 안내에서 확인한다.
