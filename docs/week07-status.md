# 7주차 — 실시간 그래프

2026-10-07: 실시간 그래프 구현 및 자동 검증 완료.

## 구현 및 사용

`gui.py`를 실행하고 **실시간 그래프** 선택 상자에서 다음 항목을 선택한다.

- RSSI (dBm)
- 신호 세기 (%) — 기존 그래프 유지
- Ping (ms) — 게이트웨이와 외부 대상
- 패킷 손실 (%) — 게이트웨이와 외부 대상
- 속도 (Mbps) — 다운로드와 업로드

측정 완료마다 모든 지표의 기록을 갱신하며 선택한 그래프에 최근 100개 측정 결과를
표시한다. 시간축은 프로그램 실행 후 경과 시간(초)이다. 그래프 선택을 바꾸어도
같은 기록을 사용한다. 연결 정보 또는 수집 설정 변경으로 세션을 교체하면 기록을
초기화하고, 같은 설정에서 중지 후 재시작하면 기록을 유지한다.

실패·미측정 값은 NaN으로 선을 끊어 표시한다. 0 ms·0 Mbps·100% 손실은 유효한 값으로
표시한다. 속도는 기존 **속도 포함 1회 예약 (약 12 MB)** 버튼으로 측정하며 미요청
주기에는 이전 속도를 재사용하지 않는다. 드문 속도 측정도 점으로 확인할 수 있다.
RSSI의 실측/추정 출처는 Dashboard에 표시한다.
