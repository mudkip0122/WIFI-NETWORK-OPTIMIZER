# 4주차 - Wi-Fi Collector 통합

상태: 구현 및 실환경 검증 완료 (2026-09-24).

## 구현

- `wifi_optimizer/collector.py`의 WiFiCollector가 Wi-Fi/RSSI·Ping·손실·수동 속도 측정을 제어한다.
- CollectorConfig에 인터페이스, 외부 Ping IPv4, 패킷 수, 측정 후 대기 간격을 지정한다.
- 기본 대기는 5초다. 측정 소요 시간이 더해지므로 시작 시각 간격은 정확히 5초가 아니다.
- 한 작업자에서 순차 측정하여 긴 측정이 다음 측정과 겹치지 않는다.
- 속도는 자동 반복하지 않는다. GUI 예약 버튼은 다음 가능한 주기에 1회만 속도를 포함한다.
- 시작 중복을 차단하고 중지·재시작을 지원한다. 재시작 전 기존 작업자의 종료를 확인한다.
- 예기치 않은 측정 예외를 오류 결과로 반환하고 다음 주기에서 재시도한다.
- 완료 결과에는 sequence와 duration_seconds가 추가된다.
- 최대 100개 결과 큐를 사용한다. 소비가 지연돼 넘치면 가장 오래된 결과를 버리고 로그에 기록한다.
- GUI는 200 ms 간격으로 결과 큐를 읽어 메인 스레드에서 화면을 갱신한다.
- 기존 실행 파일 이름을 유지하고 GUI 구현은 gui.py로 분리했다.

## 중지 및 종료

stop()은 다음 측정을 금지하고 현재 단계 종료 후 취소하도록 요청한다.
Wi-Fi 조회, IP 구성 조회, 게이트웨이 Ping, 외부 Ping, 속도 측정 사이에서 중지 여부를 확인한다.
진행 중인 OS/API 호출을 강제 종료하지 않는다. 기본 Ping 단계는 최대 약 5초,
IP 구성 조회는 최대 15초, 속도 단계는 최대 75초의 기존 제한을 따른다.
따라서 중지·창 닫기 직후 잠시 '종료 대기' 상태가 보일 수 있다.
GUI는 작업자 종료 후 로그 핸들·그래프·창을 닫는다.

## 로그

logs/collector-<세션ID>.log에 시작·중지, 측정 순번·상태·소요 시간·속도 포함 여부,
예외 종류, 큐 초과를 기록한다. SSID/BSSID 및 원본 결과를 로그에 자동으로 기록하지 않는다.
각 세션의 로그는 1 MB에서 분할하며 백업 3개를 유지한다.
세션별 파일은 별도로 남으므로 장기간 사용 시 로그 폴더 정리는 필요하다.
logs 폴더는 Git 제외 대상이다. 원본 결과 자동 DB 저장은 5주차에서 구현한다.

## 실행

```powershell
# GUI: 실행하면 자동 측정 시작
.\.venv\Scripts\python.exe "Wi-Fi Signal Strength Visualizer.py"

# CLI: 각 측정 완료 후 5초 대기, Ctrl+C로 중지
.\.venv\Scripts\python.exe -m wifi_optimizer --monitor --interval 5

# 정해진 횟수만 측정하고 종료
.\.venv\Scripts\python.exe -m wifi_optimizer --monitor --interval 5 --samples 3
```

GUI에서 간격·인터페이스·대상을 바꾸려면 중지 완료 후 수정하고 다시 시작한다.
CLI 모니터는 결과마다 JSON 한 줄을 출력한다. 개별 오류가 발생해도 계속 실행하며
정상적인 모니터 종료 코드는 0이다. 각 결과의 status를 확인해야 한다.
속도 단독 수동 실행은 기존 `--measure --speed`를 사용한다.

## 검증

- 자동 테스트 29개 통과: 기존 22개 + Collector 수명주기·취소·오류 복구 등 7개.
- 중복 시작 방지, 대기 간격, 재시작, 속도 예약 직렬화, 큐 제한, 예외 후 재측정,
  로그 생성 및 네트워크 호출 전 취소를 검증했다.
- 실제 CLI에서 Wi-Fi/RSSI·게이트웨이/외부 Ping을 2회 연속 측정, 두 결과 모두 ok.
- 실제 GUI에서 자동 측정 2회 → 중지 → 재시작 → 추가 측정 → 창 닫기 흐름을 검증했다.
- 그래프에 3개 실측 표본이 반영됐고, 창 종료 후 작업자와 로그 핸들이 종료됨을 확인했다.
- 로컬 실측 기록은 logs/week04-live.json에 저장했다 (Git 제외).
