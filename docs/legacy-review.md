# 기존 Wi-Fi Signal Strength Visualizer 검토

2026-09-24 사용자가 제공한 `Wi-Fi Signal Strength Visualizer.py`를 검토했다.
Tkinter + Matplotlib 기반 신호 % 그래프이며 NumPy로 추세와 통계를 계산한다.

사용자가 제공한 https://github.com/mudkip0122/WIFI-NETWORK-OPTIMIZER.git 는
2026-09-24 조회 시 원격 refs가 없는 빈 저장소였다. 새 프로젝트의 원격으로 사용하며,
이후 로컬에 제공된 Visualizer 파일을 분석 원본으로 사용했다.

## 분석 결과 및 수정

- 수집: `os.popen` 결과에서 한글 `신호`만 찾았다. 현재 환경의 영어 출력 및
  호출 방식에 따라 달라지는 UTF-8/CP949를 처리하도록 collectors/signal.py로 분리했다.
- 실패 시 None을 반환해 빈 그래프만 표시했다. 권한·타임아웃·누락 상태를 화면에 표시한다.
- UI 스레드의 동기 측정은 정지를 유발할 수 있어 단일 작업자에서 실행한다.
- deque(maxlen=100), 그래프 선 재사용, Tkinter 레이아웃은 유지·확장 가능하다.
- 시간축은 표본 개수였으므로 실제 경과 초로 변경했다. 추세도 같은 시간축을 사용한다.
- 텍스트 리포트와 평균/최대/최소 계산은 재사용 가능하나 현재 최근 100개 표본만 대상으로 한다.
- DB, SSID/BSSID, RSSI dBm, Ping, 공간 측정은 기존 코드에 없다. 향후 신규 구현한다.
- 별도 라이선스 선언은 파일에서 확인되지 않았다. 제3자 재배포 조건은 별도 확인한다.

검증: 자동 테스트 5개 통과, 실제 신호 100% 수집, GUI 의존성 import 및 구문 검사 성공.
추가 GUI 검증: Tk after로 갱신 시작을 보장하고 0/100% 선이 테두리에 겹치지 않게 여백과 점을 추가했다.
실제 Tk 이벤트 루프에서 6개 신호 표본과 그래프 점 6개를 확인했고 저장된 그래프 이미지도 확인했다.
리포트 저장 및 추세 버튼의 수동 조작 검증은 수행하지 않았다.
