# 9주차 — 공간별 측정

2026-10-30: 공간·지점 선택, 좌표 저장, 반복 측정 및 위치별 평균 조회 구현.

## 사용 순서

1. `.\.venv\Scripts\python.exe gui.py` 실행 후 **중지**를 누르고 종료를 기다린다.
2. **공간 / 지점 선택 → 공간 추가**에서 측정 공간을 등록한다.
3. **지점 추가**에서 이름과 x, y 좌표를 입력한다. 좌측 상단을 원점으로 오른쪽은 x, 아래쪽은 y이며 단위는 m이다.
4. 표에서 지점을 선택하고 **선택 지점 적용 → 자동 측정 시작**을 누른다.
5. 같은 위치에서 여러 번 측정한 뒤 중지한다. 다른 지점으로 이동해 선택과 측정을 반복한다.
6. 공간 창의 **평균 새로고침**으로 지점별 기록 수, RSSI·외부 Ping 평균과 표본 수, 외부 손실 평균을 확인한다.

위치 변경과 해제는 측정이 완전히 중지된 상태에서만 가능하다. 위치가 지정되지 않은 일반 모니터링도 지원한다.
공간·지점은 DB에 보존되지만 앱 재실행 시 측정 위치는 다시 선택한다.

## 저장 및 평균 기준

기존 SQLite v1 구조를 사용한다. 측정 행에 location_id, 같은 세션의 반복 그룹을 저장하고 원본 JSON에도 공간 이름·좌표·단위를 포함한다.
기존 측정 기록은 변경하지 않는다. 미지정 기록은 공간별 평균에 포함하지 않는다.
평균은 실제 데이터만 포함하며 오류·취소 측정의 지표와 실패·미측정 지표는 제외한다.
무응답의 100% 손실은 포함하고 Ping 시간은 제외한다. 기록 수에는 오류·취소도 포함한다.
각 측정의 단순 평균이며 서로 다른 AP·시각·RSSI 출처를 통합하므로 비교 시 동일 조건을 유지해야 한다.

3.6 × 3.6m 방은 **내 방 3.6 × 3.6 m** 버튼으로 등록하거나 다시 선택한다.
표시된 평면도의 빈 곳을 클릭하고 지점 이름을 입력하면 실제 m 좌표로 저장된다.
기존 지점의 점을 클릭하면 그 지점이 선택된다. **선택 지점 적용** 후 자동 측정을 시작한다.
점선 간격은 0.6m이며 좌측 상단이 (0, 0)이다. 문·가구는 표시하지 않는다.
기존 좌표 직접 입력도 지원한다. Heatmap과 자동 음영지역 분석은 다음 단계다.

## 검증

` .\.venv\Scripts\python.exe -m unittest discover -s tests -v `

좌표 범위, 빈 지점, 예제 데이터 제외, 실패 값 제외, 100% 손실, Collector의 위치·반복 그룹 저장,
공간 창의 지점 선택을 검증한다. 실제 공간을 이동하며 측정하는 현장 검증은 남아 있다.
