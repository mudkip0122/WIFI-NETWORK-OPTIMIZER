# 11월 공간 분석 진행 현황

| 주차 | 구현 내용 |
| --- | --- |
| 9주차 | 공간과 지점 등록, 좌표 저장, 반복 측정 및 위치별 평균 조회 |
| 10주차 | AP별 RSSI·외부 Ping·품질 점수 Heatmap, 보간 격자와 실측 지점 표시 |
| 11주차 | RSSI·품질 기준 설정, 저품질 지점 및 연속 음영지역 표시, 면적 비율 계산 |
| 12주차 | 지점별 규칙 기반 진단, AP 배치와 채널·대역 설정 개선 권장 |

## 측정 및 분석 순서

1. ` .\.venv\Scripts\python.exe gui.py `로 실행하고 **중지**를 누릅니다. **공간 / 지점 선택**에서 공간을 등록합니다. 가로와 세로 길이를 미터 단위로 입력하면 직사각형 지도에서 클릭해 지점을 만들 수 있습니다. 등록된 3.6 × 3.6m 방은 전용 버튼으로 선택할 수 있습니다.
2. 지점을 적용하고 **자동 측정 시작**을 누릅니다. 각 지점에서 여러 번 측정한 뒤 중지하고 다음 지점에 적용합니다. 같은 AP에 연결한 상태에서 일직선에 놓이지 않은 세 지점 이상을 측정하면 해당 지표의 Heatmap을 만들 수 있습니다.
3. **공간 분석**에서 공간, AP, 지표를 선택합니다. 측정 중에도 조회할 수 있으며, **측정 기록 새로고침**을 누르면 방금 저장된 기록이 반영됩니다. 지도 점이나 표의 행을 선택하면 지점별 평균, 표본 수, 대역과 채널, 진단 결과가 표시됩니다.
4. 기본 음영 기준은 RSSI **−75 dBm 미만** 또는 품질 **60점 미만**입니다. 화면에서 값을 변경하고 **기준 적용**을 누릅니다. 보라색 테두리는 음영으로 판정된 지점 또는 격자의 경계를 표시합니다.

## 집계 및 해석

- 기존 SQLite 기록을 BSSID와 대역 조합별로 집계합니다. 정상·부분 성공한 실제 측정 중 연결 변경 경고가 없는 값만 사용합니다. 무응답은 손실률에 반영하고 지연 평균에서 제외합니다. 종합 점수가 저장되기 전 기록에는 8주차 점수 계산식을 적용합니다. 지점 상세에 RSSI의 드라이버 조회·신호 % 환산 등 데이터 출처를 표시합니다. 외부 대상, 장치, 측정 시간과 트래픽이 비슷할 때 지점 간 차이를 비교하기 쉽습니다.
- 역거리 가중 보간(IDW)은 지표별 실측 지점의 볼록껍질 안에 있는 격자에만 적용합니다. 회색 영역은 선택한 지표의 보간 범위 밖입니다. 유효 좌표가 부족하면 실측 지점만 표시합니다. 크기가 없는 기존 공간에서는 등록된 좌표로 표시 범위를 추정합니다. 보간 모형은 벽이나 가구의 형태와 재질을 반영하지 않습니다.
- RSSI 또는 품질을 추정할 수 있는 격자를 분모로 삼아 음영 비율을 계산합니다. 변을 공유하는 음영 격자를 한 영역으로 집계합니다. 화면에서 전체 공간 중 판정 가능한 면적도 함께 확인할 수 있습니다.
- 진단은 게이트웨이와 외부 Ping·손실을 구분하고 각 제안에 규칙 ID와 근거 측정값을 표시합니다. 지연 기준은 게이트웨이 20 ms, 외부 100 ms이고 손실 기준은 각 5%입니다. AP 배치 제안은 약한 지점과 양호한 지점의 실측 결과를 사용합니다. 채널 혼잡은 주변 채널 사용량을 별도로 확인한 뒤 변경 전후를 비교합니다.
